災害写真マップの使い方

① 写真 → ② 場所 → ③ 送る

  1. 配られたリンク・QRコードで開き、必要なら合言葉を入れます。名前・所属は任意です。
  2. 現地では「いまいる場所で送る」→「撮る」。このページの「撮る」で撮ると、現在地が自動で入ります。地図と精度を確かめ、ずれていたら直します。
  3. 区分を選び、必要なら「至急」やコメントを付け、「送信する」を押します。受付番号が出れば送信済みです。

安全な場所から、全体が分かる写真と近くの写真を撮ってください。現地は写真・動画あわせて1回20件までです。

あとからまとめて送る

「あとで場所を決めて送る」で写真を選びます。写真の位置情報があれば自動で入ります。ない場合は、1枚ずつ「場所を決める」で地図・Googleマップ・目印から指定します。「前の写真と同じ場所」も使えます。分からない場合だけ「場所が分からない」を選び、本部での確認に回してください。

iPhoneで写真を選ぶときは「オプション」の「位置情報」をオンにすると、位置が残ることがあります（機種・版によります）。

カードの写真を押すと、画面いっぱいに大きく表示します。写真をもう一度押すか「閉じる」で戻れます。

動画を送る

  1. 写真を選ぶ所の「🎥 動画」を押して、撮影するか保存済みの動画を選びます。現地で選ぶと、そのときの現在地が入ります。
  2. 場所と区分を確かめ、「送信する」を押します。写真と動画を一緒に送れます。

30秒くらいがおすすめです。1本の上限は受付の設定によります（初期は100MB）。大きすぎる場合は短く撮り直してください。▶ と長さが動画の目印です。長さや画像を読み取れなくても送れます。

大きい動画は送信に時間がかかります。Wi-Fiのある所でまとめて送ってもかまいません。動画も下書き・送信待ちに保存されます。空き容量が足りず保存できなかったときは、空きを作って選び直してください。

Googleマップから場所を写す

座標は、場所を表す2つの数字です。

iPhone：地図を長押し → 下に出る数字をタップしてコピー。Android：地図を長押し → 上の検索欄の数字をコピー。

うまくいかなければ「共有」→「リンクをコピー」。投稿ページの「場所を決める」→「Googleマップの座標やリンクを貼る」に貼り、「読み取る」→「この場所に決める」を押します。短いリンクの読み取りには通信が必要です。

「送信待ち」と出たとき

写真・動画はこの端末に保存されています。電波が戻り、ページを開いていると自動で送り直します。動画は少しずつ送り、途中で切れたらサーバーが受け取った続きから再開します（送信期限が切れた場合は初めから送ります）。「動画 12MB 中 4MB」のように進み具合が出ます。「送信待ち」で理由を見たり「今すぐ送る」を押せます。送れるまではブラウザのデータを消さないでください。合言葉が変わったときは新しい合言葉を入れてください。

開き方・困ったとき

LINEなどの中で開いたら「ブラウザで開き直す」を押してください。ホーム画面に追加した場合は、合言葉の入れ直しが必要になることがあります。

写真の形式で送れない場合は、iPhoneのカメラ設定を「互換性優先」にするか、別の写真を選んでください。位置情報が取れないときは、地図で場所を指定できます。
